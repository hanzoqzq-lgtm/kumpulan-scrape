## ✨ Tentang
Repo ini berisi kumpulan kode scrape yang gw bikin dan pakai sendiri. Simpel, ringan, dan bisa jalan di Termux.

## 📂 Daftar File

| File | Fungsi |
|------|--------|
| `removeBackground.js` | Hapus background gambar |

## 🚀 Cara Pakai

```bash
git clone https://github.com/hanzoqzq-lgtm/kumpulan-scrape
cd kumpulan-scrape
npm install
node removeBackground.js
```

## 📱 Jalan di Termux

```bash
pkg update && pkg install nodejs git -y
```
